# MyCell Shopify Theme

Tema Shopify IsoTech personalizado para a loja MyCell.

## Fluxo recomendado

1. Fazer mudanças nesta pasta do tema.
2. Registrar as mudanças no Git.
3. Enviar para uma branch do GitHub conectada a um tema nao publicado na Shopify.
4. Validar no preview da Shopify antes de publicar.
